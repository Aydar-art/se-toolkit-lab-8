1. Описание проекта (для LLM) — первая готовая версия

Название: RPG To-Do Telegram Bot (Full Version)

Цель: Расширить демо-версию бота, добавив автоматическую оценку сложности задач через LLM, систему прокачиваемых навыков, выбор навыков перед боем, полноценный автоматический пошаговый бой с inline-кнопками, историю боёв и таблицу рейтинга. Все данные должны сохраняться в SQLite.

Технологии: Python 3.9+, aiogram 3.x, aiosqlite, asyncio, HTTP-клиент (aiohttp) для вызова LLM API.

Новые функциональные требования (поверх демо-версии):

LLM-оценка сложности задачи (опционально, включается настройкой):

При добавлении задачи пользователь может выбрать: ввести ОД вручную или получить оценку от LLM.
При выборе LLM бот отправляет название задачи во внешнее API (YandexGPT, GigaChat, OpenAI, DeepSeek и т.п.) и получает число от 1 до 8.
Оценка сохраняется как ОД задачи.
Система навыков:

Каждый навык — это особое действие в бою (например, «Сильный удар»: 10 урона за 3 ОД).
Навык открывается после выполнения цепочки реальных задач (например, «сделать зарядку 3 дня подряд»).
Прогресс открытия навыка отслеживается в отдельной таблице player_skills и skill_chains.
После открытия навык доступен навсегда.
Перед боем игрок выбирает до 3 навыков из числа открытых.
Полностью автоматизированный пошаговый бой с inline-кнопками:

Бой инициируется командой /fight @username.
Бот отправляет сопернику запрос с inline-кнопками «Принять» / «Отказаться».
После принятия создаётся боевая сессия. Бот автоматически определяет очерёдность ходов (по ОД или случайно).
Во время хода игроку показываются inline-кнопки: «⚔️ Атака (1 ОД)», «💪 Сильный удар (3 ОД)» (и другие выбранные навыки), «🛡️ Защита (0 ОД, снижает след. урон на 50%)».
Бот обрабатывает нажатия, обновляет HP и ОД, отправляет обновлённый статус боя обоим участникам.
Бой заканчивается, когда у одного из игроков HP ≤ 0. Победитель получает +50 XP, проигравший +10 XP.
История боёв:

Каждый завершённый бой записывается в таблицу fight_history (дата, игроки, победитель, сколько ОД потрачено, какие навыки использовались).
Команда /history показывает последние 5 боёв текущего игрока.
Рейтинг игроков:

Команда /rating показывает топ-10 игроков по количеству побед в дуэлях.
Рейтинг обновляется после каждого боя.
Ежедневный сброс ОД (уже был в демо, но теперь нужно убедиться, что он работает корректно с новыми таблицами).
База данных (дополнительные таблицы):

skills — список всех доступных навыков (id, name, description, od_cost, effect_type, effect_value, unlock_condition).
player_skills — какие навыки открыты у игрока (user_id, skill_id, unlocked_at).
skill_progress — прогресс по цепочкам для открытия навыков (user_id, skill_id, current_step, target_steps).
fight_history — записи о боях (id, player1_id, player2_id, winner_id, player1_od_spent, player2_od_spent, skills_used_json, date).
players (расширяется): добавить поле wins (количество побед).

Шаг 3: Система навыков и прогресс открытия

В database.py добавить функции:

get_skill_progress(user_id, skill_id) — текущий прогресс по цепочке.
update_skill_progress(user_id, skill_id, increment=1) — увеличить прогресс после выполнения соответствующего действия.
unlock_skill(user_id, skill_id) — открыть навык.
Определить условия открытия для каждого навыка (хранить в БД или в коде). Например:

«Сильный удар»: выполнить 3 задачи типа «зарядка» (можно по ключевым словам или отдельный тип задач). Для упрощения: использовать счётчик выполнения любых задач подряд 3 дня.
«Защита»: выполнить 5 задач с низкой ОД (1-2) за неделю.
«Восстановление»: спать 8 часов 2 дня (потребует отдельной команды /sleep, фиксирующей сон).
Реализовать фоновую проверку прогресса после выполнения каждой задачи (в хендлере /complete вызывать update_skill_progress для соответствующих навыков).
Добавить команду /skills — показать список открытых навыков и прогресс по ещё не открытым.
Шаг 4: Выбор навыков перед дуэлью

Модифицировать команду /fight: после того как соперник принял вызов, перед началом боя каждому игроку отправить inline-клавиатуру со списком его открытых навыков (максимум 3). Игрок выбирает, какие навыки он возьмёт в бой.
Сохранить выбранные навыки в сессии боя (временное хранилище в памяти).
После того как оба выбрали, начать бой.
Шаг 5: Полностью автоматизированный бой с inline-кнопками

Создать новые состояния в states/fight_states.py: FightStates.waiting_for_opponent, FightStates.selecting_skills, FightStates.in_fight.

Callback для выбора навыков → сохранение выбора, проверка, что оба выбрали.

После окончания боя: начислить XP, обновить поле wins победителя, записать бой в fight_history, очистить сессию.
